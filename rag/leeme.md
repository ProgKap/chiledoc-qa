chiledoc-qa es un sistema de preguntas y respuestas sobre documentos construido con RAG (Retrieval-Augmented Generation) que corre completamente local, sin depender de ninguna API externa de pago. La idea nació de una necesidad simple: quería poder hacerle preguntas a un documento en lenguaje natural y obtener respuestas precisas basadas en su contenido real, sin que el modelo inventara nada.
El sistema toma cualquier documento, lo trocea en fragmentos, los convierte en embeddings y los almacena en una base vectorial. Cuando haces una pregunta, el sistema busca los fragmentos más relevantes y se los pasa al modelo junto con la consulta para que genere una respuesta fundamentada en el texto original. Todo el procesamiento ocurre en tu máquina con Ollama como motor de inferencia local.
Stack: Python, LangChain, Ollama, ChromaDB, embeddings locales.
Para usarlo: clona el repo, instala las dependencias con pip install -r requirements.txt, asegúrate de tener Ollama corriendo con el modelo que prefieras, coloca tu documento en la carpeta indicada y ejecuta el script principal. Desde ahí puedes hacer preguntas directamente por consola.
